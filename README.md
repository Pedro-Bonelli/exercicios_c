# Lista de exercícios em C

Exercícios independentes de programação em C reunidos em `Lista_Exercicios/`, com arquivos numerados, `teste.c` e uma configuração local do VS Code em `.vscode/`.

## Estrutura

- Arquivos `.c`: exercícios independentes (ou o programa indicado acima).
- Pastas `Lista_Exercicios/`, `Testes/` ou `output/`, quando presentes: organização dos códigos e artefatos.

## Como executar

Requisito: GCC configurado no terminal.

```bash
git clone https://github.com/Pedro-Bonelli/exercicios_c.git
cd exercicios_c
gcc Lista_Exercicios/ex01.c -o programa
./programa
```

No PowerShell do Windows, execute `./programa.exe` (ou `.\programa.exe`). Cada arquivo `.c` é um exercício independente, salvo indicação no próprio código.

## Observações

A configuração de `.vscode/` pode referenciar caminhos do computador em que foi criada; confira o compilador se o F5 não funcionar no PC novo.
